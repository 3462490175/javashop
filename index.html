核心特性

覆盖分布式系统核心命题的六大能力实践

⚡

微服务架构治理

基于 Spring Cloud Alibaba 完成服务拆分与治理，Nacos 承担注册发现与统一配置中心，OpenFeign 实现声明式远程调用，服务间解耦清晰。

🛡️

统一网关与限流

Gateway 作为系统唯一入口，集中处理路由转发、鉴权与跨域；集成 Sentinel 实现流量控制与熔断降级，保障高并发下核心链路稳定。

🔄

分布式事务

使用 Seata AT 模式 跨 goods、order 服务保证数据一致性，配合本地事务与全局事务协同，解决下单扣库存的超卖与脏数据问题。

📨

消息驱动解耦

RocketMQ 承载订单异步通知、支付回调与流量削峰，将非核心链路从主流程剥离，显著降低下单响应时间并提升系统吞吐。

🔒

缓存与分布式锁

Redis + Redisson 构建多级缓存体系，分布式锁保障秒杀库存扣减的原子性；结合布隆过滤器与逻辑过期策略防范缓存击穿与穿透。

🔍

搜索引擎与数据同步

Elasticsearch + IK 中文分词支撑商品全文检索与高亮；Canal 监听 MySQL binlog 实现数据库到索引的准实时增量同步。
